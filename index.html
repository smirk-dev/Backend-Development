How to run an experiment locally

KindCommand
Static (01, 07 & 08)py -3 -m http.server 8000 from the experiment folder, then open http://localhost:8000
Node (12, 12B, 13A, Exam 01)npm install then npm start from the experiment folder, then open http://localhost:3000
MongoDB experiments (13A, Exam 01)A MongoDB server on localhost:27017 must be running first
